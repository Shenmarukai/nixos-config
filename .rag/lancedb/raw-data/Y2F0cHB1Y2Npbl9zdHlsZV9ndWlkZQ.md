## Style Guide

- The theme uses pastel colors to provide a soothing visual experience.
- Use the 'Mocha' flavor for dark mode as it has a warm, muted appearance that works well for coding environments.
- For GTK themes: Install using `gtk-theme-install` or manually place theme in ~/.themes/ folder.
- For Qt applications: Use Qt style plugins with custom color schemes (e.g., qdarkstyle).
